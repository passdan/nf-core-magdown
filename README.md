## Introduction

**nf-core/magdown** is a pipeline for downstream analysis of metagenomic assembled genomes (MAGs) focussing on wastewater samples. 

It is designed to initially run from completed nf-core/mag outputs but should be able to accept any MAG inputs.

2. Present QC for raw reads ([`MultiQC`](http://multiqc.info/))
3. AMR annnotation ([`Abricate`](https://github.com/tseemann/abricate))
4. Plasmid identification ([`plasmidfinder`](https://github.com/genomicepidemiology/plasmidfinder))
99. Summarise outputs ([`MultiQC`](http://multiqc.info/))


## Usage

Now, you can run the pipeline using:

<!-- TODO nf-core: update the following command to include all required parameters for a minimal example -->

```bash
nextflow run nf-core/magdown \
   -profile <conda/docker/singularity> \
   --input samplesheet.csv \
   --outdir <OUTDIR>
```

> [!WARNING]
> Please provide pipeline parameters via the CLI or Nextflow `-params-file` option. Custom config files including those provided by the `-c` Nextflow option can be used to provide any configuration _**except for parameters**_; see [docs](https://nf-co.re/docs/running/run-pipelines#using-parameter-files).

For more details and further functionality, please refer to the [usage documentation](https://nf-co.re/magdown/usage) and the [parameter documentation](https://nf-co.re/magdown/parameters).
